# CS4.0-AC
шифрование текста на алгоритме шифрования CS3.0-AC

CS4.0-AC — экспериментальный алгоритм симметричного шифрования текстовых данных в растровые изображения.

 Особенности:

•Визуальное кодирование: преобразует исходный текст в массив пикселей, визуально напоминающий статический шум (белый шум).

•Скрытие структуры: стирает характерные паттерны и частотность исходного текста, усложняя классический криптоанализ.

Преимущества:

•Шифр очень удобен в использовании

•Абсолютно криптостоек к частотному анализу

•В отличии от других шифров (например, AES-254) CS4.0-AC выглядит как обычный арт или сломанный телевизор, и не вызывает интереса у злоумышленника



Инструкция:

1. Подготовка среды разработки.

Откройте Android-проект в среде Android Studio.Подключите к проекту плагин для запуска Python-кода (рекомендуется Chaquopy). Задайте в настройках сборки версию Python, которая использовалась при создании данного шифра.

2. Перенос файлов шифра

Создайте в исходных файлах Android-приложения отдельную папку для Python-скриптов.Скопируйте файл шифра из этого репозитория в созданную папку.

3. Установка внешних библиотек

Если скрипт шифрования использует дополнительные модули (например, для работы с криптографией), укажите их названия в настройках сборки Android-приложения. Встроенный менеджер пакетов автоматически скачает их и упакует в приложение.

4. Связывание языков и вызов функций

В коде мобильного приложения настройте запуск среды Python при старте программы.В блоке логики, где требуется шифрование, обратитесь через плагин к загруженному Python-файлу.Передайте текст и ключ шифрования из интерфейса приложения в функцию скрипта и заберите обратно готовый зашифрованный результат.
