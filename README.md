# CS3.0-AC
шифрование текста на алгоритме шифрования CS3.0-AC

Краткое описание:

CS3.0-AC - один из самых сильнейших алгоритмов шифрования. Он основывается на сложно-структуризированном шифровании текста в картинки чем то напоминающие экран сломанного телевизора. CS3.0-AC неоднократно проходил тестирование и является очень надёжным шифром, взлом которого невозможен, так как алгоритм предусмотривает все возможные виды взлома. 




Инструкция:


Для активации шифрования введите в появившееся окно команду cipher.ru затем нажмите Enter
