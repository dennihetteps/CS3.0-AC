# CS3.0-AC
шифрование текста на алгоритме шифрования CS3.0-AC

CS3.0-AC — экспериментальный алгоритм симметричного шифрования текстовых данных в растровые изображения.

 Особенности:

•Визуальное кодирование: преобразует исходный текст в массив пикселей, визуально напоминающий статический шум (белый шум).

•Скрытие структуры: стирает характерные паттерны и частотность исходного текста, усложняя классический криптоанализ.


Инструкция:

1.Откройте главную страницу нужного репозитория на GitHub.

2.Найдите кнопку с надписью «Code» (в правой части экрана, прямо над списком папок и файлов)

3.Нажмите на неё — откроется небольшое выпадающее меню.

4.В самом низу этого меню нажмите на строчку «Download ZIP» (Скачать ZIP).

5.Откройте папку со скриптом. Распакуйте скачанный архив и зайдите в папку, где лежит файл шифра.

6.Откройте Терминал в этой папке.
 
7.Нажмите правой кнопкой мыши на саму папку (или на пустом месте внутри неё) и выберите пункт «Новый терминал в папке» (New Terminal at Folder).

8.Активируйте скрипт. Скопируйте команду ниже, вставьте её в открывшееся черное окно Терминала и нажмите Enter: chmod +cipher.ru
