# CS3.0-AC
шифрование текста на алгоритме шифрования CS3.0-AC

CS3.0-AC — экспериментальный алгоритм симметричного шифрования текстовых данных в растровые изображения.

 Особенности:

•Визуальное кодирование: преобразует исходный текст в массив пикселей, визуально напоминающий статический шум (белый шум).

•Скрытие структуры: стирает характерные паттерны и частотность исходного текста, усложняя классический криптоанализ.

Преимущества:

•Шифр очень удобен в использовании

•Абсолютно криптостоек к частотному анализу

•В отличии от других шифров (например, AES-254) CS3.0-AC выглядит как обычный арт или сломанный телевизор, и не вызывает интереса у злоумышленника



Инструкция:

1.Перейдите на страницу этого репозитория на GitHub и в правом сайдбаре откройте раздел Releases (Релизы).

2.Скачайте установочный файл с расширением .apk.

3.Откройте скачанный файл на вашем Android-смартфоне.

4.Если система выдаст предупреждение безопасности, нажмите «Настройки» и включите тумблер «Разрешить установку из этого источника».

5.Вернитесь назад и нажмите «Установить». На рабочем столе телефона появится фиолетовая иконка приложения с ключом.
